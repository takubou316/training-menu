# この教科書の位置づけ（読み進める前に踏まえておくこと）

『健康運動実践指導者 養成用テキスト』（公益財団法人 健康・体力づくり事業財団）の「はじめに」を読んで
分かった、教科書全体の前提。今後どの章を読むときも、この前提を踏まえて内容を解釈する。

## 発行元と成り立ち

- 発行元は公益財団法人 健康・体力づくり事業財団。1964年の東京オリンピック開催を契機に閣議決定された
  国の健康づくり施策に当たってきた団体
- 国の政策の流れ：
  - 昭和53年(1978) 第1次国民健康づくり対策 — 治療重視から予防重視への転換、「栄養・運動・休養」のバランス確立
  - 10年後 第2次(アクティブ80ヘルスプラン) — 栄養偏重で不足していた運動を重視、実践指導者の養成を開始
  - 平成元年(1989)〜 第3次以降（健康日本21等） — 科学的根拠(エビデンス)に基づく基準・ガイド策定

## 想定している対象者（重要）

**この資格・教科書が育てようとしている指導者が対象とする相手は、競技スポーツの選手やハードに
トレーニングしている人ではなく、子供から高齢者まで含む「一般国民」。** 「はじめに」に明記されている
目的は、「少子・超高齢社会」を背景に、単に病気の早期発見・治療にとどまらず、**発病を防ぐ「一次予防」・
生活の質(QOL)の向上**を目指すこと。つまり全体を通して「健康づくり」「予防医学」寄りの内容であり、
アスリート向けのパフォーマンス最大化やボディメイクに特化した内容ではない可能性が高い。

## 位置づけの更新（2026-08-08）

ユーザーから「これらの教科書群をtraining-menuの情報の基盤にしたい、信頼している」との方針が示された。
これにより、今回集めた教科書（健康運動実践指導者テキスト、JATIトレーニング指導者テキスト
理論編/実践編/実技編）は、単なる「参考にする外部知識」ではなく、**training-menuの運動科学的な
内容（セット/レップ/休憩・動作テンポ・フォームのポイント・安全上の注意等）の一次情報源**として扱う。

既存コード（`rules.js`・`exercises-data.js`）のコメントは「ACSM/NSCA等の一般的知識」という
漠然とした出典表記だったが、今後数値や記述を更新する際は、この教科書群を具体的な出典として
明記していく。教科書間で数値の食い違いがある場合や、既存のACSM/NSCA的な数値と異なる場合は、
基本的に教科書側（特にJATI実践編、対象が「一般人からスポーツ選手まで」で本人の想定ユーザー層に近い）
を優先する。ただし、[[project_textbook_knowledge_extraction]]の方針通り、教科書の文章を
そのまま転記はせず、知識として要約・構造化してから反映する。

なお、下記「training-menuへの適用時の注意」（健康運動実践指導者テキスト＝一般人・高齢者向けという
前提）は、JATI教科書群（一般人〜スポーツ選手まで対象）が加わったことで一部緩和される。数値の
対象読者層を都度確認する必要性は残るが、「使えない」という結論ではなく「どの教科書のどの記述が
本人の状況に近いか」を選ぶという方向性になる。

## training-menuへの適用時の注意（元の記載、参考情報として残す）

[current-app-knowledge-review.md](current-app-knowledge-review.md)で「rules.jsの数値の裏付けに
第7章・第8章Eを読むとよい」としたが、上記の前提を踏まえると：

- この教科書に出てくるセット数・レップ数・強度の目安は、**一般人・高齢者を含む健康づくり目的の
  数値である可能性が高い**（既存の`rules.js`はACSM/NSCAの筋力トレーニング的な文脈の数値、
  例えば筋肥大目的なら8〜12回、を使っている）
- 対象者層がそもそも違う可能性があるので、教科書の数値が出てきても**単純に上書きしない**。
  「一般人・高齢者向けの安全側の目安」として参照しつつ、training-menuの想定ユーザー（本人の
  トレーニング強度）に合うかどうかを都度判断する
- むしろこの前提は、training-menuに既にある以下の設計判断の裏付けとして相性が良い：
  - 気になる部位・痛みの事前ヒアリング機能（`riskAreas`によるfilterByPainAreas）
  - 初心者(beginner)向けに技術難度の高い種目を除外する`minLevel`の仕組み
  - レベル別のセット数・ウォームアップセット数の調整
  → これらは「万人向けの安全な運動指導」という教科書の目的意識と一致する部分なので、
  今後の章でこうした配慮についての具体的な記述が出てきたら、上記機能の精度向上に使いやすいはず
