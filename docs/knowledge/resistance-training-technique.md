## 1. 動作スピードの目安（table 1、rules.jsにない新情報）

目的別に「上げる動作」「下ろす動作」の速度が変わるという考え方。今の`rules.js`の`GOALS`には
レップ数・休憩時間はあるが、**動作スピードの目安は存在しない**。

| 目的 | 上げる動作 | 下ろす動作 |
|---|---|---|
| フォームの習得 | 2〜3カウント（一定スピード） | 2〜3カウント（一定スピード） |
| 筋肥大 | 2カウント（一定スピード） | 2カウント（一定スピード） |
| 筋力・パワー向上 | 全力スピード | 1〜2カウント（一定スピード） |

→ 「スローリフティング」（加速を制限してゆっくり行う）と「スピードドリフティング」
（できるだけ素早い速度で筋力・パワーを高める）という2つの代表的な動作スピード方法がある。

## 2. 呼吸法

- **努責を避ける呼吸法**（一般的・推奨）：低〜中負荷では「下ろす局面で吸う→上げる局面で吐く」。
  引く動作（ベントオーバーロウ等）は胸郭が開くタイミングに合わせて「上げる局面で吸う→下ろす局面で吐く」
  になることもある。
- **努責を伴う呼吸法**（バルサルバ法、経験者の高負荷限定）：下ろす時に吸って最下点で息を止めて挙上、
  スティッキングポイント通過後に吐く。腹圧が高まり姿勢を保ちやすく大きな力を発揮しやすいが、
  血圧の急激な上昇・めまいのリスクがあるため**中高齢者や初心者には推奨されない**。

## 3. 補助法（スポッティング）

- 個人指導は指導者自身が、多人数指導は実施者間で補助
- 重量物が落下する危険のある種目（肩より上に挙上する種目、バーベルを担ぐ種目）は補助が必須
- 高齢者・低体力者は上記以外の種目でもふらつき・転倒に備えて補助を検討
- 補助を始めるタイミングの目安：動作が遅くなる／フォームが崩れる／呼吸が乱れる／表情が苦しそう

## 4. 高齢者・低体力者への配慮（4点）

1. **シートや背もたれの使用**：立位で正しい姿勢を保てない場合、座位・背もたれ固定に変更
2. **可動域の調整**：関節可動域や筋の張りに応じて無理のない範囲にする
3. **動作の開始ポジションの工夫**：できるだけ筋力を発揮しやすい位置から開始（例：チェストプレスは
   補助者やフットバーでバーを押した状態から始める）
4. **呼吸法やカウントの工夫**：努責による血圧急上昇を防ぐため呼吸法を徹底、指導者が「吸って」
   「吐いて」と声をかける。動作テンポを一定に保つため指導者がカウントする

→ training-menuの`LEVELS`（初心者/中級者/上級者）や`minLevel`機能の配慮の方向性と一致する。

## 5. 器具の安全確認（トレーニング器具の使用に関する留意点）

- バーベル：プレートは左右均等・2名で同時装着、必ずカラーを取り付ける、シャフトの曲がりを確認
- マシン：使用前にシート/パッド位置を調整、ケーブルのアタッチメントを確実に接続
- ラック：フックの高さ・セーフティバーの位置を適切に調整

## 6. 代表的エクササイズ30種目（使用部位・共通する起こりやすい誤り）

各種目に[使用部位][実技（ポジショニング・動作）][呼吸法][補助法][起こりやすい誤り]が
セットで解説されている。training-menuの`exercises-data.js`と対応する種目のみ、使用部位と
主な「起こりやすい誤り」（フォームチェックポイントとして使えそう）を抜粋する。

### 胸部（5種目）
| 種目 | 使用部位 | 起こりやすい誤り（抜粋） |
|---|---|---|
| ベンチプレス | 大胸筋・三角筋前部・上腕三頭筋 | 足が床から離れる／殿部が浮き腰が反る／肩甲骨が過度に外転／肘が胴体に近づき肩が外旋／手首が背屈／バーベルが斜めに上がる |
| インクラインベンチプレス | 大胸筋(上部)・三角筋前部・上腕三頭筋 | ベンチプレスと同様＋インクライン角度は30〜40度が目安 |
| ダンベルベンチプレス | 大胸筋・三角筋前部・上腕三頭筋 | ベンチプレスと同様。ダンベルを落とすと肩に過剰負担がかかるため「オンザニーテクニック」（大腿部を使って開始・終了時にダンベルを安全に扱う）が有効 |
| ダンベルフライ | 大胸筋・三角筋前部 | 肘を軽く曲げたまま肩を中心とした円軌道。足が床から離れる／腰が反る／肩甲骨が過度に外転 |
| シーティッドチェストプレス（マシン） | 大胸筋・三角筋前部・上腕三頭筋 | 腰が反る／肩が前方に移動／手首が背屈／後頭部がシートから離れる |

## training-menuへの反映案

1. **`rules.js`の`GOALS`に動作スピード(テンポ)の目安を追加**：現状レップ数・休憩時間のみだが、
   「上げる〇カウント・下ろす〇カウント」を目的別に追加できる（新情報、今までなかった軸）
2. **`exercises-data.js`の該当種目の`description`に「起こりやすい誤り」を反映**：現状の`description`は
   フォームのポイントのみ簡潔に書かれているが、上記の「起こりやすい誤り」から重要なものを1〜2個
   追記すると、初心者向けのチェックポイントとして機能しそう
3. **呼吸法の一般原則**（低〜中負荷は下ろす時に吸い上げる時に吐く、高負荷・経験者限定でバルサルバ法）
   を種目説明や記録画面のヒントに反映できるか検討
4. 高齢者・低体力者への配慮4点は、既存の`minLevel`・`riskAreas`機能の設計思想の裏付けとして使える
