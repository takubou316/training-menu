## A. クールダウンに有酸素運動ステップを追加するか

現状：`buildWarmupAndCooldown`の`cooldown.general`が「深呼吸1〜2分」のみ。

必要な情報：
- [ ] 有酸素クールダウンの**具体的な種類**（ジョギング/ウォーキング以外に何が使えるか。器具を使わない自重系の
      メニューでも実行可能な「その場で足踏み」等のバリエーションは教科書に例があるか）
- [ ] 「最低5〜10分」の根拠が、**主運動の強度**によってどう変わるか（軽い運動後も同じ5〜10分必要か、
      それとも主運動の強度に応じて短縮できるか）
- [ ] 教科書のどこか他の箇所に、有酸素クールダウンを省略してよいケースの記載がないか

確認先：第7章「健康づくりと運動プログラム」のウォームアップ/クールダウン節（p109〜111、まだ未読）に
もう少し詳しい記載がある可能性がある。

## B. ウォームアップの有酸素時間を可変にするか

現状：`warmup.general`が「5分」固定。

必要な情報：
- [ ] 「全体運動時間の10%前後」を**下限・上限**でどう丸めるか（例：15分メニューなら1.5分では短すぎないか、
      教科書に最低ラインの記載はあるか）
- [ ] 気温・季節を考慮する場合、アプリはユーザーの居住季節・室内外情報を持っていないため、
      **実装するかどうか自体を判断する必要あり**（情報不足というより設計判断。教科書を読んでも決まらない）

確認先：Aと同じ第7章p109〜111。季節要因は今回読んだp130で十分（追加取材は不要）。

## C. ウォームアップの動的な動きに「短い静的ストレッチ」を足すか

現状：`DYNAMIC_WARMUP_BY_PATTERN`は回数ベースの動きのみ。

必要な情報：
- [ ] 動作パターン（squat/hinge/push_horizontal等）ごとに対応する**具体的な10秒ストレッチの内容**
      （[warmup-cooldown-stretching.md](warmup-cooldown-stretching.md)の部位別一覧はあるが、
      「動作パターン」への対応づけは自分たちで考える必要がある＝教科書には載っていない、独自マッピング作業）
- [ ] 既存の`STATIC_STRETCH_BY_MUSCLE`（クールダウン用）を10秒版として流用してよいか、
      それとも別内容にすべきか（教科書は同じストレッチでも保持時間だけ変える想定なので、
      流用で問題なさそうという仮説はある）

確認先：教科書からの新規取材は不要。既存ノートの情報＋自分たちでのマッピング設計が必要。

## D. クールダウンのストレッチに優先順位をつけるか

現状：使った主動筋を全部機械的に列挙。

必要な情報：
- [ ] 「疲労感の強い部位」をアプリがどう判定するか（ユーザーの主観申告が必要になり、UIの追加が必要。
      教科書には判定方法までは書かれていない＝これも設計判断）
- [ ] 「過去に傷害歴のある部位」は既存の「気になる部位」設定（肩・腰・膝・手首）と統合できそうか
- [ ] 実装するなら、**全部位を出さずに絞る**のか、**優先順位で並び替えるだけ**にするのか

確認先：教科書に判定ロジックはない（一般論のみ）。実装方針はUI/UXの相談が必要。

## E. セルフマッサージを追加するか

必要な情報：
- [ ] 図8A-2の6種類のうち、**器具を使わずどこでもできるもの**を絞り込めているか
      （[warmup-cooldown-stretching.md](warmup-cooldown-stretching.md)に既に6種類記録済み、追加取材は不要）
- [ ] ストレッチと別枠で見せるか、置き換え選択肢として見せるか（設計判断）

確認先：情報は揃っている。実装方針の相談のみで着手可能。

## F. rules.jsのセット/レップ/休憩数値の裏付け

現状：8-12回/90秒（筋肥大）等、ACSM/NSCA一般知識ベースで既に実装済み。裏付けが取れれば
コード変更ではなく「コメントに出典を補強する」「教科書独自の数値があれば見直す」に使う。

必要な情報：
- [ ] 教科書側のレジスタンス運動の負荷設定（レップ数・セット数・休憩時間）の目安値
- [ ] 現在の数値と大きくズレる場合、どちらを優先するか（既存はACSM/NSCA系の一般知識、
      教科書は日本の公益財団法人の資格テキストなので、対象読者層や想定強度が違う可能性に注意）

確認先：**第7章p120〜124「レジスタンス運動」**、**第8章E p182〜196「レジスタンス運動(1)(2)(3)」**（未読）

## G. riskAreasの精度向上

必要な情報：
- [ ] 図8A-9で確認した「腰」「膝」の危険な動き（未読）以外に、他の部位（肩・手首）で
      同様の「避けるべき動き」の記載が教科書にあるか
- [ ] 第9章「運動障害と予防・救急処置」の整形外科的障害の節（p213〜220）に、
      部位別のリスク要因がまとまっていないか

確認先：**第9章 p197〜222**（未読）。特にp213「整形外科的障害と外科的救急処置」。
