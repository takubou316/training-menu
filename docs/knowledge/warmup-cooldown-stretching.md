## ウォームアップ

### 何をやるか
1. **低〜中強度の有酸素運動**（ウォーキング・ジョギング・自転車こぎなど）で体温を上げる
2. **四肢・体幹の関節を大きくゆるやかに動かす軽い体操**で筋への血行を促進
3. **主運動で使う部位を中心に、10秒程度の短い静的ストレッチ、または動的ストレッチ**
   （ストレッチだけで済ませるのはNG。あくまで①②とセットで行うウォームアップの一部）

ラジオ体操のような徒手体操は健康づくりの定番だが、中高年・高齢者には不向きな動作
（大きな体幹の回旋、跳躍を伴う脚の開閉、深い膝の屈曲、弾みをつけた上体の捻転、
頭部の急激な位置変化）を含むことがあるため、対象者の年齢・体力レベルに応じて動きを選ぶ必要がある。

### どのくらいの時間・強度で
- 運動時間全体の**10%前後**が目安（1時間の運動なら5〜10分）
- 十分にできたかの目安：体温上昇・発汗、主な筋や関節がほぐれる、心拍数が主運動の目標強度の下限に近づく
- 強度は**弱いところから徐々に上げる**（漸増）。ストレッチも狭い可動域から徐々に広げる
- 冬など気温が低いときは体温上昇に時間がかかるため長めに念入りに行う

### 環境条件に応じた調整
- **夏**：直射日光を避け木陰などで、こまめな水分補給。外気温が高く体温上昇が容易なので、ウォームアップ自体は短めでもよい（その分、体をほぐす部分はしっかり行う）
- **冬**：寒冷環境は循環器に負担が大きい（血圧上昇、特に高血圧の人は要注意。急な血圧上昇は脳出血・脳梗塞・心筋梗塞のリスクにつながりうる）。体が冷えたまま運動を始めると筋・腱・靭帯・関節を痛める危険もある。できるだけ暖かい室内で、暖かい時間帯に、十分に体を温めてから外に出る。携帯カイロやサウナスーツも短時間昇温に有効
- 主運動が複雑・特異的な動作（球技・武道・ダンスなど）で構成される場合は、その基本動作をウォームアップに組み込むとスムーズに移行できる
- 主運動の種類によって負担がかかりやすい部位が異なる（例：ウォーキング/ジョギング→下肢筋群、ラケットスポーツ→利き腕の筋群）ので、そこを重点的にストレッチ/軽い筋活動でほぐす
- 屋外運動の場合、ストレッチやレジスタンス運動はできるだけ立位でできる方法を選ぶ

## クールダウン

### 何をやるか（ウォームアップとほぼ逆の流れ）
1. **低〜中強度の有酸素運動を最低5〜10分**（心拍数・呼吸・血圧を穏やかに安静へ戻す）
2. **主な関節をほぐす軽い体操・主要筋群の静的ストレッチ・セルフマッサージ**で体温を徐々に下げつつ筋を弛緩

### どのくらいの時間で
- 全体の運動時間の**10%前後**（1時間のプログラムなら最後の5〜10分）

### 実施上の注意
- **主運動でよく使い、負担のかかった部位を優先的にケア**する（例：走る・跳ぶ・ダンス・球技など体重負荷型運動では下腿三頭筋の疲労度が大きい）
- 運動強度は**漸減**させる（ウォームアップの逆）。ウォーキング/ジョギングなら速度を、自転車なら負荷を徐々に下げる
- 時間が十分取れない場合は優先順位をつける：**疲労感の強い部位／過去に傷害歴がある部位／その主運動で筋肉痛や慢性障害を起こしやすいとされる部位**を優先
- 汗が冷えて風邪をひかないよう、上着を着るなど保温に配慮する

### セルフマッサージの例（図8A-2）
1人でできる方法として、以下のような動きが紹介されている（張りを感じる部位を「さする」「揉む」「軽くたたく」「押す」）：
- 足裏を親指で押す（指圧）
- 大腿前部・大腿外側・ふくらはぎ/すねをこぶしで軽くたたく
- 仰向けで両手両足を挙げてぶらぶら振る
- 仰向けで両膝を胸に抱え込み、かかとで殿部を軽くたたく

マッサージには末梢→心臓方向（西洋流）と中心→末梢方向（東洋の按摩）の考え方があるが、
専門家でない一般の人が行う場合は厳密な方向にこだわらず、気持ちよく血行を促す程度でよい。

## ストレッチングの基礎知識

### 静的ストレッチング（スタティック）
反動をつけずゆっくり伸ばし、その状態を保持する方法。**一般の人が健康づくり目的で行う場合は
安全性・有効性・簡便性の観点からこれが推奨される**。

筋の中の「筋紡錘」というセンサーが急激な伸張を感知すると、逆にその筋を収縮させる防御反射
（伸張反射）が働く。ゆっくり伸ばすことでこの反射を避けられる。一方、腱にある「腱紡錘（ゴルジ腱器官）」は
ある程度の張力がかかると逆に筋を弛緩させる方向に働くため、静的ストレッチは伸張反射を避けつつ
弛緩効果も得られる合理的な方法といえる。

### 動的ストレッチング（ダイナミック）
動きながら筋や腱を伸ばす方法。反動・はずみを使う「バリスティックストレッチング」は
伸張反射を誘発して筋や腱を痛める危険があり、**一般人の健康づくり運動としては推奨されない**。
一方、主働筋の収縮で拮抗筋が緩む性質（相反性神経支配）を利用した反動なしの動的ストレッチは、
特定のスポーツ動作に近い形で柔軟性を高められ、ウォームアップに向く。

### PNFストレッチング（参考・パートナーが必要）
パートナーに抵抗をかけてもらい、伸ばしたい筋の拮抗筋を最大収縮させた直後に脱力すると、
その筋がよく弛緩し可動域が広がる方法。1人では十分に伸ばしきれない場合に有効だが、
補助者の技術が前提となるため一般ユーザー向けアプリでの再現は難しい（参考情報にとどめる）。

### ガイドライン（ACSM＝アメリカスポーツ医学会）
- **保持時間**：10〜30秒（高齢者は30〜60秒でより効果が得られる）
- **反復回数**：2〜4回
- **頻度**：最低週2〜3回、毎日行うのが最も効果的

### 実施上の9つのポイント
1. 心身ともにリラックスし、できるだけ脱力して行う
2. **筋が温まった状態で行う**（冬に寒い場所で行う場合は要注意。日常生活では入浴後が効果的）
3. 反動をつけずゆっくり伸ばし、痛みを感じない範囲で10〜30秒保持
4. 息を止めず自然な呼吸を続ける
5. 安定した姿勢で行う（立位より座位・臥位のほうが安定しやすい。屋外で立位のときは壁や柱、二人一組の支え合いも有効）
6. どの筋を伸ばしているか意識する（姿勢だけ真似るのではなく、伸びている感覚を意識すると効果が高い）
7. 他人と比較しない（関節可動域には個人差が大きい）
8. 全身バランスよく行いつつ、酷使した部位・凝りやすい部位（大腿裏、股関節、腰部など）は重点的に
9. 段階を追って行う（最初は10秒程度の軽いストレッチ→少し強く伸ばして30秒保持、というように徐々に）

### 目的・効果
柔軟性（関節可動域）の向上だけでなく、傷害予防、ウォームアップ/クールダウンの一部としての活用、
疲労回復、リラクセーションが主な目的。ただし**クールダウンでのストレッチは運動後の遅発性筋肉痛
そのものは軽減しないことが報告されている**（それでも血行促進・リラクセーションとしては有効）。
過度な柔軟性はかえって関節の外傷・障害リスクを高めるため、適度な獲得を目標とする。

高齢期には、加齢や活動不足による筋・腱の拘縮を防ぎ、衣類の着脱や靴下を履く、爪を切るといった
日常動作の保持にも役立つ、という記載もある。

## 部位別ストレッチング一覧（図8A-1・8A-6、姿勢つき）

教科書には各部位につき「立位」「座位」「椅座位」「仰臥位」「横臥位」などの姿勢バリエーション込みで
やり方の説明文と図が付いている。training-menuの`riskAreas`（肩・腰・膝・手首）や
`MUSCLE_GROUPS`（[exercises-data.js](../../js/exercises-data.js)）と対応させやすい部位一覧：

| 部位 | 主な方法（例） |
|---|---|
| 頸部 | 手の重みで頭を側方/斜め前/後方に倒し、頸部の筋を伸ばす |
| 体側 | 両手を組んで上方挙上、または片腕を伸ばして反対の手で手首を引く |
| 胸部・肩 | 両手を背中で組んで後方に引き上げる／壁に手をつき体を前に向ける |
| 上背部・上腕背部 | 両手を前に伸ばして背中を丸める／肘を曲げて反対の手で引き寄せる |
| 前腕部 | 四つんばいで指先を自分側に向けて腰を引く／伸ばした腕の手先を反対の手で引く |
| 大腿前部 | 片脚のかかとを殿部に近づける（立位・座位・横臥位いずれも可） |
| 大腿後部（ハムストリングス） | 片脚を前に伸ばし反対脚の膝を曲げて上半身を前傾（立位・椅座位・座位・仰臥位） |
| 大腿内側 | 両膝を曲げ足裏を合わせて座り、両肘/両腕で膝を床方向に押す |
| 大腿外側 | 片脚を前に伸ばし反対脚を交差させて大腿外側を引き寄せる |
| ふくらはぎ・すね | 脚を前後に開き後ろ脚の膝を伸ばしかかとを床につける／片脚の甲を床に押しつける |
| 腰部・殿部 | あぐらで上半身を前傾／仰向けで片膝または両膝を胸に引き寄せる |
| 側腹部 | 仰向けで両膝を横に倒す／椅子で上半身をひねる |
| 脚の付け根（股関節） | 両脚を前後に開き体重を支えながら後ろ脚の付け根を伸ばす |

## 避けるべきとされるストレッチング姿勢の例（図8A-9、p143）

一般の人が健康づくり目的で行うにはリスクが高く、推奨されないとされる例。安全な代替法があるものは
図8A-6の該当項目に置き換え可能（教科書内の対応：aは⑧⑩、b/c/dは⑩、eは⑫の方法に代替できるとの記載）。

| 例 | 動作 | リスク |
|---|---|---|
| a. ヨガ・プラウ | 仰向けから脚を頭の上まで持っていく | 頸椎に大きな負担をかける |
| b. ハードラーズ・ストレッチ | 片脚を大きく横に曲げて座り前傾する（ハードル選手のような座位） | 鼠径部の筋・靭帯、膝の内側側副靭帯を過伸展させる |
| c. トウ・タッチング | 立位で前屈し、爪先に触れる | 腰部に過度の負担をかけ、腰痛の原因になりうる |
| d. バレエ・ストレッチ | バーなどに片脚を高く乗せて上半身を倒す | 膝後部や腰背部の靭帯・筋・関節・椎間板・座骨神経を過度に伸展させ、腰痛や下肢痛の原因となる |
| e. ニー・ストレッチ | 体育座り姿勢から上体を後方に反らす | 膝蓋靭帯・側副靭帯の過伸展を招き、腰部にも負担がかかる |

→ training-menuの`riskAreas`（腰・膝）の判定材料として使える。特に「腰」「膝」を気になる部位に選んだ
ユーザーに、こうした姿勢に近いストレッチを提案しない/注記する、という使い方ができそう。
